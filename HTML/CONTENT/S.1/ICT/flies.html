File and Folder Management

In this topic, you will look at the basics of file and folder management. You will learn how files and folders are created, manipulated, organised and accessed on a computer.

Getting Started

In this topic, you will look at the basics of file and folder management, but first, let's start by defining some of the most relevant terminologies as shown below.

Terminology Definition
Folder A virtual container in which files on a computer are stored.
File A virtual item that is stored on a computer.
Icon A graphical representation of a program or command on a computer.
Sub-folder A folder that is placed in or is a child of another folder.
Copy To duplicate an item on a computer and place it on the system's clipboard.
Cut To move an element from its original location to the clipboard or another location.
Paste To move an item placed on the clipboard to a new location.
Clipboard An area in computer memory where items that have been copied or cut are placed for future use or reference.

Folders

As stated above, a folder is a virtual container in which files on a computer are stored.

In the world of ICT, every advanced computer user applies their knowledge of files and folders to arrange their work, protect it, ease file access and significantly boost productivity.

In the same way, different computer programs use the principles of file and folder management to safely access, store and make use of their source files.

Creating a Folder

A folder can be created using three distinct ways. The most common and easiest way of creating a folder is by navigating to the folder's new location using File Explorer.

To open File Explorer, use the keyboard combination Windows + E or simply type File Explorer in your Windows search box.

Once the window is open, navigate to the preferred location of the folder and use the "New folder" option in the Home tab.

Once this has been done, you can use the newly created folder to store and organise your files.

Manipulating Folders

Once a folder has been created, various actions can be taken upon it. In File Explorer, these actions are reflected in the ribbon and become active once the folder has been selected.

Folder Actions

Opening

This refers to the process of viewing the contents of the folder.

Cutting

This is the moving of a folder from its original location to another location or to the system's clipboard.

Copying

This involves copying an item from its original position to the system's clipboard.

Renaming

This involves modifying the name of the folder.

Deleting

This is moving the folder to the system's recycle bin or permanently erasing it from the computer.

Content Specification

This is the specification of the type of items which will be stored in the folder. This is done through the folder's properties.

Compressing and Zipping

This is the process of making the folder's contents occupy less disk space to ease storage and sharing.

Accessing Folders

To access a folder, a person must know the location of the folder in the local file system.

This is done with the help of a File Path, which is a tree-like guide through various directories and sub-folders to where the folder is located.

Uses of Folders

  • For storing files.
  • For separating and arranging files to prevent disorganisation and confusion.
  • They help to ease file access.
  • For protecting files from unauthorised access.
  • For backing up files.

Files

A file is a virtual item that is stored on a computer. Basically, the normal usage and running of a computer depends on the manipulation of folders needed by the user and the manipulation of different files needed by both the computer's operating system and installed software.

A file can be an image, a document, a spreadsheet, a code file, etc.

Note

The process of manipulating and accessing files using File Explorer is generally the same as that for folders. The following sections focus on the important file-specific concepts.

Creating Files

A file can be created by navigating to the desired location using File Explorer and selecting the New Item option from the ribbon and selecting the desired file type.

Alternatively, right-click in the body of the desired location and select the New option from the pop-up menu.

Identifying Files

The process of identifying files is made easier by the use of file extensions.

A file extension is an addition to the file name that identifies different types of files, their uses and the applications that can be used to open them.

To view the different extensions on your device, search and open Command Prompt and type assoc on the command line.
